
# АС «МойОбъект»

Автоматизированная информационная система **«МойОбъект»** — это единая цифровая платформа для управления нежилыми помещениями.  
Система автоматизирует процессы контроля эксплуатации и помогает принимать операционные решения.

##  Правила работы с ветками (Git Flow)

Мы используем **Git Flow** для организации разработки.

### Основные ветки (постоянные):
- **`main`** — стабильный код, готовый к релизу (продакшн).
- **`develop`** — основная ветка разработки, куда сливаются все фичи.

### Временные ветки (создаются по необходимости):

| Тип ветки    | Шаблон            | Назначение                              |
|--------------|-------------------|----------------------------------------|
| **feature**  | `feature/<name>`  | Разработка новой фичи                   |
| **release**  | `release/<ver>`   | Подготовка релиза                        |
| **hotfix**   | `hotfix/<name>`   | Срочное исправление на продакшене       |

### Примеры:
```
feature/login-form
release/1.0.0
hotfix/fix-critical-bug
```

### Итоговая структура:
```
main       # стабильный продакшн код
develop    # текущая разработка

feature/...   # новые фичи
release/...   # подготовка релиза
hotfix/...    # экстренные исправления
```
> Остальные ветки создаются при необходимости через Pull Request.

## Правила коммитов

Мы используем **Conventional Commits** для единообразия истории репозитория.

### Формат:
```
<type>(scope): <short summary>
```

### Основные типы:
| Тип       | Описание                          | Пример                     |
|-----------|-----------------------------------|----------------------------|
| **feat**  | Новая фича или функционал         | `feat(auth): add login`    |
| **fix**   | Исправление бага                  | `fix(api): handle 500`     |
| **docs**  | Обновление документации           | `docs: update README`      |
| **style** | Только стили (пробелы, формат)    | `style(ui): fix padding`   |
| **refactor** | Рефакторинг без изменения логики | `refactor(api): simplify`  |
| **test**  | Добавление или правки тестов      | `test(auth): add tests`    |
| **chore** | Рутинные задачи, конфиги, CI      | `chore: update deps`       |

### Примеры:
```
feat(profile): add avatar upload
fix(dashboard): correct data sorting by date
docs: update project setup guide
```

> 💡 **Совет:**
> - Сообщения пишем на английском.
> - Коротко и по делу — до 72 символов в заголовке.
> - Перед merge — убираем мусорные коммиты через squash/rebase.
